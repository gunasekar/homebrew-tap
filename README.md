# gunasekar/tap

Homebrew formulae by [@gunasekar](https://github.com/gunasekar).

```console
brew install gunasekar/tap/trails
```

| Formula | What it is |
|---|---|
| [`trails`](https://github.com/gunasekar/trails) | Pick, rejoin and restore AI coding agents running in tmux |

To update a formula after a new release, bump `url` to the new tag and set
`sha256` to the tarball's hash:

```console
curl -sL https://github.com/gunasekar/trails/archive/refs/tags/vX.Y.Z.tar.gz | shasum -a 256
```
